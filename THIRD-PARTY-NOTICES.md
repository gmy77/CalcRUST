# Dipendenze di terze parti

CalcRUST usa librerie Rust pubblicate su crates.io. Versioni e checksum sono bloccati in Cargo.lock.

Le copie dei file di licenza e degli avvisi disponibili nei pacchetti delle dipendenze Windows sono conservate senza modifiche nella cartella THIRD-PARTY-LICENSES. Sono compresi gli avvisi dei font predefiniti del motore grafico. Ogni dipendenza mantiene la propria licenza; questa raccolta non attribuisce una nuova licenza al codice delle dipendenze.

Componenti principali: eframe/egui ed egui_plot per interfaccia e grafici, chrono per il calendario, serde per la persistenza, reqwest/rustls per HTTPS, image per le anteprime, num-bigint/num-rational/num-traits per l'aritmetica esatta.

Segoe UI e Segoe UI Symbol non sono inclusi nei pacchetti CalcRUST: vengono letti dal sistema Windows quando presenti. Non viene distribuito codice o materiale grafico della Calcolatrice Microsoft. Microsoft e Windows sono nomi dei rispettivi titolari; il progetto non è affiliato a Microsoft.
